# Sistema de Gestión de Viáticos

Sistema web desarrollado para el control y gestion de viáticos en comisiones de trabajo del organismo CAPCEE puebla.

## Tecnologías utilizadas
- PHP
- Laravel
- MySQL
- HTML, CSS, JavaScript

## Funcionalidades principales
- Registro de comisiones
- Control de viáticos (alimentos y peajes)
- Cálculo automático de reintegros y abonos
- Gestión de documentos (solicitud y comprobación)
- Control de estatus de comprobación

## Descripción
Este sistema fue desarrollado como parte de mi residencia profesional, enfocado en resolver la gestión administrativa de viáticos, automatizando cálculos y seguimiento documental.
